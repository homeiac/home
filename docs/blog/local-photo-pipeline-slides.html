What went wrong—and what fixed it.

Both were waiting on the same storage path.

Run large archive imports on the storage host.

The speed graph kept rising and falling

File totals were only updated every five minutes.

Count descriptions as they are saved.

The laptop slept. Cloud work stopped.

The laptop was sending the requests.

Move that job to a computer that stays on.
