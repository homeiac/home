01 / How it works

Keep the originals. Describe them locally.

Photos path shown; Drive/OneDrive use the existing copy job. USB covers the quota subset, not all photos. Optional Luna sends media/context to a cloud service. Visual captions + Whisper speech feed saved stories; private originals remain the evidence. Resources still use the Flux preview branch.
